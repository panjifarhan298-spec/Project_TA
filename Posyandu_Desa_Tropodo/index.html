Tentang Posyandu

Sistem Informasi Posyandu Desa Tropodo

Aplikasi ini membantu kader dan bidan desa memantau kesehatan masyarakat secara terintegrasi.

  • Data Balita: Pemantauan status gizi dan deteksi dini risiko stunting.
  • Data Ibu Hamil: Pengawalan usia kehamilan dan hari perkiraan lahir (HPL).
  • Data Lansia: Pemeriksaan berkala tekanan darah dan kondisi fisik lansia.
Halaman GitHub Pages hanya menampilkan informasi. Login, statistik, dan pengelolaan data memerlukan server PHP dan database.
